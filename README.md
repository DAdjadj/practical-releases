# Practical

A small macOS menu bar app that shows your next calendar event or reminder, with a month
calendar, quick add and search one click (or ⌥⌘N) away.

This repository only holds the downloads. Get the latest version from
[Releases](https://github.com/DAdjadj/practical-releases/releases/latest).

## Install

1. Download `Practical.zip` from the latest release and unzip it.
2. Move **Practical** to your Applications folder and open it.
3. The first time, macOS may say it can't verify the app. Open System Settings > Privacy & Security,
   scroll down and click **Open Anyway**. This is needed once.
4. Allow access to Calendar, Reminders and Contacts when asked.

Requires macOS 14 or later, on Apple Silicon or Intel. Practical updates itself: it checks once a day,
or choose Check for Updates from the gear menu.

## Privacy

Everything stays on your Mac. Practical reads your calendars, reminders and contacts through macOS
and never sends them anywhere: no accounts, no analytics, no servers. The only network request it
makes is the update check, which asks GitHub for the latest version number and contains nothing
about you.
